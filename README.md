## Featured Project

# Event Registration & Attendance Management System

## Project Summary

This is a full end-to-end automation system developed using Python and enterprise technologies. The system manages event registration, attendance tracking, data processing, and reporting through an integrated workflow.

It demonstrates practical experience in software development, database integration, and automation engineering.

---

## Objectives

- Automate event registration and attendance management
- Eliminate manual data handling processes
- Ensure data integrity and validation
- Generate structured reports automatically
- Improve operational efficiency using Python automation

---

## System Architecture

The system is built using:

- Python (core application logic)
- Oracle Database 12c (data storage layer)
- cx_Oracle (database connectivity)
- Pandas (data processing and transformation)
- OpenPyXL (Excel reporting automation)
- QR Code generation (attendance tracking system)

---

## Key Features

### Event Registration Module
- User registration with structured data input
- Data validation and duplicate prevention
- Clean and standardized record creation

### Database Integration
- Oracle Database integration using cx_Oracle
- Automated insertion and updating of records
- Centralized data storage and management

### QR-Based Attendance System
- Unique QR code generation for participants
- Fast attendance marking using QR scanning logic
- Efficient tracking of event participation

### Data Processing & Automation
- Data cleaning and transformation using Pandas
- Automated workflows for handling registration data
- Structured and scalable processing pipeline

### Reporting System
- Automated Excel report generation using OpenPyXL
- Participant lists and attendance summaries
- Structured output for operational reporting
